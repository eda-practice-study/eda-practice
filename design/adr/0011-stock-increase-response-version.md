# 0011 재고 증가 응답의 두 수량은 같은 DB 버전을 기준으로 한다

- 상태: 채택
- 적용 범위: 재고 증가 API 응답
- 기록일: 2026-11-08

## 배경과 결정

지연된 요청의 DB 수량과 더 최신인 Redis 수량을 함께 반환하면 실재고보다 가용 재고가 많아 보인다.
Redis가 요청보다 최신 버전이면 쓰기를 건너뛰고 `availableQuantity`는 `null`로 반환한다.
같은 버전 또는 최신 버전 반영에 성공하면 해당 수량을 반환한다. 기존 Redis 호출 실패도 `null`을 유지한다.

## 의미와 검증

두 값이 모두 숫자이면 같은 DB 버전이며, 응답 시점에도 최신이라는 보장은 아니다.
`null`은 해당 버전의 가용 재고를 제공할 수 없다는 뜻이며 DB 증가 실패를 의미하지 않는다.
대사는 건너뛰기를 장애로 처리하지 않는다. 역순 반영과 지연된 증가의 응답 및 최종 DB·Redis 상태를 통합 테스트로 확인한다.
